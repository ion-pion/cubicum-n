CUBICUM N

A small operating system that lives in a 7 × 7 × 7 cube. Written in Oberon, compiled to native code on the phone itself, and running on Android today. It is a game, and it is also a real system.

Oberon-07 → LLVM built on the phone with Byz7 343 cells · Cubicum FS hosted or bare metal version 17

What it is

Cubicum N is one native app: a desktop, a shell, a synthesizer, a file system and an archiver. Every piece is an Oberon module, and every piece was written and rebuilt on a Samsung Galaxy A15.

The cube

The home screen is a live 7 × 7 × 7 lattice. Each cell that holds a file lights up in gold. Drag it to turn it.

Shell

An Oberon shell over Tor7, a spiral of 7 turns where programs run side by side. RUN, EDIT, NOTE, ARCH, APPS, OPEN …

Synth Z7

Each node of the cube is a note in just intonation. Keys, sequencer, recorder and a player.

Cubicum FS

Files have an address instead of a path: seven digits from 1 to 7 and a cell in the cube.

Z7 Arch

A modular archiver in 64 KB cells. You can search it and take out a single piece, and it knows images, sound and video.

The host

When it runs on Android it lists and opens the phone's apps. When it runs alone, on bare metal, it shows only its own.

Boot

The boot comes from Cubicum OS, the March 2026 version that ran in a web page:

  • The void, then the egg.
  • The Salamandra comes out of the egg and swims around the cube.
  • The cube lights up from its centre, shell by shell, while the synth sweeps up two octaves from the cube's lowest note.
  • Five clocks beat at /1 /2 /3 /5 /7, and the log scrolls on the left.

While the boot plays, Cubicum N asks its host for the list of apps. By the time the desk is shown, the list is already there.

Files & settings

FILES shows the Cubicum FS cube and the list of files. When you tap a file, its cell turns red and grows.

  • OPEN opens it in the editor, and RUN runs a .mod or .z7 program.
  • PACK puts it into a Z7 Arch cube, and UNPACK takes the files back out.
  • DELETE asks once more before it deletes.

SETTINGS opens when you tap the status bar. You can pick one of 5 accent colours, turn the boot screen and the spinning cube on or off, show the FPS, and replay the boot. ABOUT shows the host and its device.

How it is built

There is no PC in the loop. The source is plain Oberon-07 modules. OLL, an Oberon-to-LLVM compiler, turns them into ARM64 code inside Byz7, a terminal app on the same phone, and a single command builds the APK.
